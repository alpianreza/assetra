# 08_API_DESIGN.md

- **Prefix**: `/api/v1`
- **Domains**:
    - `/auth`, `/users`, `/roles`
    - `/assets`, `/inventory`
    - `/compliance` (checklist templates, logs, questionnaire)
    - `/notifications`
    - `/reports`
    - `/audit`
    - `/settings`
- **Removed**: Any Patrol or IT Monitoring endpoints.
