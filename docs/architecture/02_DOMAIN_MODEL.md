# 02_DOMAIN_MODEL.md

### Core Domains
- **Auth**: User authentication, RBAC.
- **Organization**: Company profile, Areas.
- **Inventory/Asset**: Assets, Inventory, Categories, Types (with `checklist_frequency`).
- **Compliance**: Checklist Templates, Checklist Questionnaires (with `allow_na`), Checklist Logs.
- **Notifications**: Reminders, Delivery channels (WhatsApp/Email).
- **Reports**: Print/Export functionality.
- **Audit**: Activity and action logging.
