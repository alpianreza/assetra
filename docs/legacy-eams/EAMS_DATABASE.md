# EAMS DATABASE

- **Driver**: MySQL
- **Tool**: CodeIgniter Migration System
- **Key Tables**:
    - `users`: User authentication, roles, page access, PIC.
    - `compliance_inventory`: Assets and inventory linked to inspection types.
    - `asset_item_types`: Asset classifications and checklist frequencies.
    - `checklist_templates`: Checklist definitions.
    - `checklist_logs`: Inspection evidence and results.
    - `patrol_sessions/logs`: Security patrol features.
    - `audit_logs`: Activity and action logging.

- **Status**: Migration map must be carefully reviewed for Assetra implementation.
